How to Use It

1. Click on the grid blocks above to toggle musical steps for your currently active instrument tab. Use the bottom playhead row to view current sequence positioning.
2. Use the parameters tab panel to dynamically customize physical parameters of each instrument sound.
3. Drop inside a cover art file (PNG, JPEG, GIF) and click "Export Studio MP4" to instantly compile a visually synced 1kHz - 21kHz spectrum analysis video.

How it Works

Zyper utilizes the high-precision browser-native Web Audio API to compile physical audio models (using delay waveguide loops, lowpass feedback damping, and noise-burst filters). The Three.js and WebXR engines simultaneously parse active musical coordinate layers, enabling virtual physical mapping in standard 3D space and immersive virtual reality environments.

Why We Made It

Zyper Music Studio was created to bridge the gap between abstract 2D step sequencers and physical 3D spatial environments. By providing seamless accessibility across desktop, mobile, and WebXR headsets alongside high-fidelity visualization exports, we hope to democratize generative composition workflows.
